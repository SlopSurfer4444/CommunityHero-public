# CommunityHero

Рабочее место оператора для обработки публичных комментариев: очередь, обсуждение с ассистентом, черновики, знания компании и подтверждение действий. Сервер написан на Rust, интерфейс — на JavaScript. Данные и история операций принадлежат CommunityHero; социальная сеть подключается через заменяемый адаптер.

Это development snapshot исходников последнего согласованного BAW-кандидата от 7 октября 2026 года. Приёмка продолжается; это не стабильный релиз и не готовая установка для реального аккаунта. Он содержит Rust core, миграции PostgreSQL, SQLite-реализацию, интерфейс, CLI, адаптерные контракты и синтетические проверки. Пример нормализованных правил LikeAvto от 23 сентября сохранён как исторический пример, не как действующая BAW-политика. Клиентские комментарии, строки БД, сессии операторов, ключи, модели, установленный runtime и частный коннектор Angry.Space не включены. Включённые правила — конфигурационный пример, который не активируется при запуске. Private company knowledge allowlist заменён пустым; два compile fixtures заменены синтетическими. Поэтому публичная версия не воспроизводит текущие рабочие знания и правила BAW. Новые adapter wrappers используют закрытый transport при реальном подключении; его реализация исключена, а локальный launcher использует fail-closed bridge.

## Что где находится

- `mvp/server/src/` — API, хранение, фоновые задания, знания, подготовка и границы подтверждения.
- `mvp/server/migrations/` — фактическая схема PostgreSQL; создание SQLite описано в коде хранения.
- `mvp/workshop/` — интерфейс, который обслуживает сервер; `mvp/web/` — отдельный ранний React-клиент.
- `mvp/adapters/`, `mvp/cli/` — интерфейсы подключений и CLI. Для реального провайдера нужны отдельная реализация и конфигурация.
- `mvp/tests/` — синтетические проверки. Историческое имя `knowledge-real-cases.json` сохранено для совместимости тестов, но его содержимое полностью синтетическое.
- `project/rules-normalization-candidate-2026-09-23/` — правила, типизированный план и синтетические сценарии; `project/adrs/` — архитектурные решения.

## Локальная разработка

Нужны установленный Rust с поддержкой edition 2024, Node.js 24.15+ и PowerShell 7 для приведённого launcher. Зависимости Rust закреплены в Cargo.lock. Первый build скачивает их; `--offline` подходит только при заполненном локальном Cargo cache.

Из корня репозитория:

```powershell
cargo build --locked --manifest-path mvp/server/Cargo.toml --bin communityhero-server
./dev.ps1
```

Launcher запускает сервер в текущем терминале на `http://127.0.0.1:4186`, использует отдельную пустую SQLite в `mvp/data/public-dev`, явно выключает фоновые интеграции и внешние записи, выбирает адаптер, возвращающий `ADAPTER_DISABLED`. Профиль `likeavto` задаётся явно как поддерживаемая конфигурация модели; подключения к реальному аккаунту нет. Пустой интерфейс не является ошибкой импорта: клиентские данные в снимке отсутствуют. Остановка — Ctrl+C.

Это режим разработки на localhost. Для реальной эксплуатации отдельно нужны БД, доступ операторов, секреты, настроенные подключения, инструменты обработки медиа и проверенная процедура развёртывания. Старые рабочие launchers и portable packager, зависящие от частного коннектора, намеренно не включены. Наличие кода отправки не включает внешние записи: сервер требует отдельного явного разрешения и подтверждения конкретного действия оператором. Сборка Rust, запуск сервера и подключение реальных аккаунтов этого development snapshot здесь не проверялись; соответствующие команды описывают локальный путь разработки, а не готовую рабочую установку.

## Проверки

```powershell
cargo check --locked --manifest-path mvp/server/Cargo.toml --all-targets
node --test mvp/tests/materials-import-contract.test.mjs mvp/tests/active-instructions.test.mjs mvp/tests/headless-cli.test.mjs mvp/tests/workspace-delta.test.mjs mvp/tests/evaluation/evaluate.test.mjs mvp/tests/evaluation/model-review.test.mjs mvp/adapters/assistant-rule-semantics.test.mjs
node project/rules-normalization-candidate-2026-09-23/verify.mjs
```

Эти Node-проверки используют синтетические данные и подменённые вызовы. Полный набор содержит отдельные интеграционные проверки, которым нужны явно выделенная БД или локальные инструменты; их нельзя считать проверенными простым запуском команд выше. Синтетические проверки не доказывают качество ответов на клиентских данных, готовность к 100 компаниям или готовность публикаций в соцсетях. Результаты проверки именно этого снимка находятся в `VALIDATION.md`.

`SOURCE-ADMISSION-20261007.json` содержит исходные пути и SHA-256 согласованной генерации, исключения и синтетические replacements. `SOURCE-ADMISSION.json` сохранён как историческая граница экспорта от 23 сентября. База изменена локально, поэтому её commit не идентифицирует полный снимок. Точные опубликованные байты перечислены в `SOURCE-MANIFEST.json`; сам manifest исключён из собственного списка во избежание рекурсии. История исходного репозитория не переносилась.

## Версии и вклад

Снимок от 23 сентября остаётся доступен в [истории публичного репозитория](https://github.com/SlopSurfer4444/CommunityHero-public/tree/b3af575a1234972511955e7fda0caaf06492bbb2). Его результаты проверки не перенесены на новую версию. Текущий снимок описывает собственный продуктовый core; частный connector, installed runtime и корпоративные данные не публикуются.

Автор проекта отвечает за продуктовые сценарии, архитектурные решения, оркестрацию AI-агентов, интеграцию и приёмку. Реализация, тесты и ревью выполняются с AI coding agents; это не заявление о ручном авторстве каждой строки. AGENTS.md и skills задают ограничения и проверки в рабочей среде; личные инструкции не входят в публичный экспорт.
