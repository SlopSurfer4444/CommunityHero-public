# CommunityHero

Рабочее место оператора для обработки публичных комментариев: очередь, обсуждение с ассистентом, черновики, знания компании и подтверждение действий. Сервер написан на Rust, интерфейс — на JavaScript. Данные и история операций принадлежат CommunityHero; социальная сеть подключается через заменяемый адаптер.

Это публичный снимок исходников от 23 сентября 2026 года, а не готовая установка для реального аккаунта. Он содержит текущий MVP, миграции PostgreSQL, SQLite-реализацию, тесты и пример нормализованных правил LikeAvto. Клиентские комментарии, строки БД, сессии операторов, ключи, модели, установленный runtime и частный коннектор Angry.Space не включены. Включённые правила — конфигурационный пример, который не активируется при запуске.

## Что где находится

- `mvp/server/src/` — API, хранение, фоновые задания, знания, подготовка и границы подтверждения.
- `mvp/server/migrations/` — фактическая схема PostgreSQL; создание SQLite описано в коде хранения.
- `mvp/workshop/` — интерфейс, который обслуживает сервер; `mvp/web/` — отдельный ранний React-клиент.
- `mvp/adapters/`, `mvp/cli/` — интерфейсы подключений и CLI. Для реального провайдера нужны отдельная реализация и конфигурация.
- `mvp/tests/` — синтетические проверки. Историческое имя `knowledge-real-cases.json` сохранено для совместимости тестов, но его содержимое полностью синтетическое.
- `project/rules-normalization-candidate-2026-09-23/` — правила, типизированный план и синтетические сценарии; `project/adrs/` — архитектурные решения.

## Локальная разработка

Нужны установленный Rust с поддержкой edition 2024, Node.js 22+ и PowerShell 7 для приведённого launcher. Зависимости Rust закреплены в Cargo.lock. Первый build скачивает их; `--offline` подходит только при заполненном локальном Cargo cache.

Из корня репозитория:

```powershell
cargo build --locked --manifest-path mvp/server/Cargo.toml --bin communityhero-server
./dev.ps1
```

Launcher запускает сервер в текущем терминале на `http://127.0.0.1:4186`, использует отдельную пустую SQLite в `mvp/data/public-dev`, явно выключает фоновые интеграции и внешние записи, выбирает адаптер, возвращающий `ADAPTER_DISABLED`. Профиль `likeavto` задаётся явно как поддерживаемая конфигурация модели; подключения к реальному аккаунту нет. Пустой интерфейс не является ошибкой импорта: клиентские данные в снимке отсутствуют. Остановка — Ctrl+C.

Это режим разработки на localhost. Для реальной эксплуатации отдельно нужны БД, доступ операторов, секреты, настроенные подключения, инструменты обработки медиа и проверенная процедура развёртывания. Старые рабочие launchers и portable packager, зависящие от частного коннектора, намеренно не включены. Наличие кода отправки не включает внешние записи: сервер требует отдельного явного разрешения и подтверждения конкретного действия оператором.

## Проверки

```powershell
cargo check --locked --manifest-path mvp/server/Cargo.toml --all-targets
node --test mvp/tests/active-instructions.test.mjs mvp/tests/headless-cli.test.mjs mvp/tests/workspace-delta.test.mjs mvp/tests/evaluation/evaluate.test.mjs mvp/tests/evaluation/model-review.test.mjs mvp/adapters/assistant-rule-semantics.test.mjs
node project/rules-normalization-candidate-2026-09-23/verify.mjs
```

Эти Node-проверки используют синтетические данные и подменённые вызовы. Полный набор содержит отдельные интеграционные проверки, которым нужны явно выделенная БД или локальные инструменты; их нельзя считать проверенными простым запуском команд выше. Синтетические проверки не доказывают качество ответов на клиентских данных, готовность к 100 компаниям или готовность публикаций в соцсетях. Результаты проверки именно этого снимка находятся в `VALIDATION.md`.

`SOURCE-ADMISSION.json` содержит относительные исходные пути и SHA-256, включая идентификатор базового коммита. База была изменена локально, поэтому этот commit не идентифицирует полный снимок. Точные опубликованные байты перечислены в `SOURCE-MANIFEST.json`; сам manifest исключён из собственного списка во избежание рекурсии. История исходного репозитория не переносилась.
